# Право & смысл

Двухстраничный адаптивный сайт частной юридической практики. Создан на HTML, CSS и небольшом JavaScript для ежедневного анекдота. Не требует сборки, пакетов, внешних шрифтов или API.

## Просмотр

Из корня репозитория:

```sh
python -m http.server 8000
```

Откройте `/lawyer/index.html` на сервере. Можно также открыть `index.html` напрямую в обычном браузере. Для GitHub Pages при публикации корня репозитория путь сайта — `/Codex-work/lawyer/`; корневой магазин кроссовок сохранён.

## Страницы

- `index.html`: рекламный слоган, направления практики, весы правосудия, цитаты Цельса и Ульпиана с указанием источников.
- `services.html`: шуточный прайс из шести услуг, анекдот дня, раздел для контактных данных.
- `daily-joke.js`: 31 анекдот; выбор по местной календарной дате посетителя. Ротация повторяется через 31 день. Обновление в следующую полночь и при возвращении на вкладку. Данные никуда не отправляются. Без JavaScript показывается один запасной анекдот и пояснение.
- `styles.css`, `assets/`: общая адаптивная стилизация и локальные SVG.

## Перед использованием как сайта юриста

Замените условный бренд на имя или название практики; добавьте настоящие контактные данные в разделе `#contact` страницы `services.html`; согласуйте реальные услуги и цены. Сейчас цены прямо обозначены как демонстрационные, контакты и запись не подключены. Результат дела не гарантируется. Форм сбора персональных данных нет.

## Проверки

Проверены внутренняя навигация, якоря, наличие ресурсов, альтернативные описания изображений и структура header/main/footer. Логика анекдота проверена на постоянство внутри дня, смену в полночь, смену месяца, возврат на вкладку и 31 различный анекдот за 31 день.

Плагин Sites в сессии недоступен; эти файлы являются самостоятельным статическим сайтом, не публикацией в Sites.
